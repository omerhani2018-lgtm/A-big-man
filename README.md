# A BIG MAN  (Godot 4.3 project)

A 3D open-world life simulator. You just turned 18. Find a job, earn money,
get a home and a car, make friends, fall in love, get married and start a family.

Everything (city, buildings, people, cars, UI) is generated by code, so there
are no missing art or sound files. Open the folder in Godot and press Play.

## Run it on your computer first (easiest way to test)
1. Download **Godot 4.3** (standard version, not .NET) from https://godotengine.org/download
2. Unzip A_BIG_MAN.zip somewhere.
3. Open Godot, click **Import**, choose the `project.godot` file in the folder, click **Import & Edit**.
4. Press **F5** (or the Play button, top right). Controls on PC: WASD move, Shift run,
   Space jump, E interact, C camera, mouse drag to look.

## Easiest way to get the APK: let GitHub build it for you (no Android tools needed)
1. Make a free account at github.com and create a new empty repository (name it `a-big-man`).
2. Upload everything inside the unzipped `a_big_man` folder to it, **including the hidden `.github` folder**
   (on the website: Add file > Upload files, then drag the folder contents in; if `.github` does not
   upload, create the file `.github/workflows/build-apk.yml` by hand and paste in its contents).
3. Open the **Actions** tab. A run called "Build Android APK" starts by itself (or click it, then **Run workflow**).
4. After about 5-10 minutes, open the finished run and download **ABigMan-apk** from the Artifacts section.
   Unzip it to get `ABigMan.apk`, copy it to your tablet and install it (allow "Install unknown apps").
Note: this workflow was written but could not be test-run by me, so if the run fails, copy the red error text to me.

## Or build the APK yourself on a computer
You do this once on a Windows/Mac/Linux computer:
1. Install **Android Studio** (https://developer.android.com/studio). Open it once and let it
   install the Android SDK. Also install **OpenJDK 17** (Android Studio includes one).
2. In Godot: **Editor > Editor Settings > Export > Android**. Set:
   - Java SDK Path = your JDK folder
   - Android SDK Path = the SDK folder from Android Studio
   - Debug Keystore: click the folder icon and let Godot create it (or run
     `keytool -genkey -v -keystore debug.keystore -alias androiddebugkey -storepass android -keypass android -keyalg RSA -keysize 2048 -validity 9999 -dname "CN=Android Debug,O=Android,C=US"`
     and point to that file; user = androiddebugkey, password = android).
3. **Project > Install Android Build Template... is NOT needed.** Instead go to
   **Editor > Manage Export Templates > Download and Install**.
4. **Project > Export > Add... > Android**. Set:
   - An "Android" export preset is already included in this project; just check its settings
5. Click **Export Project**, name it `ABigMan.apk`, untick "Export With Debug" only if you
   have a release keystore; otherwise leave it ticked.
6. Copy the APK to your tablet (USB cable, Google Drive, or email to yourself).
   On the tablet open the APK file and allow **Install unknown apps** when asked.
   Or, with USB debugging on and the tablet plugged in, click the **Android** icon at the
   top right of Godot to run it directly.

## How to play
- Left stick: move. Drag anywhere else on the screen: look around.
- ACT: talk, enter shops, buy, drive. JUMP / RUN / CAM (first/third person).
- PHONE: status, GPS, people you know, save, settings.
- You can stay at your parents for 7 days. Then you need your own place.
- Jobs: Cashier and Construction need nothing. Delivery needs your own car.
  Office jobs unlock after you have worked 6 / 25 shifts.
- Friends: chat, compliment, gifts and hangouts raise friendship. Romance options
  appear with Sofia, Emma, Nina and Hannah at 60+ friendship. Marriage needs 85+, a baby 90+.
- Sleeping at a home you own, rent or at your parents autosaves.

## Project layout
- `scripts/game_state.gd`   money, time, needs, save/load, settings (autoload)
- `scripts/game_data.gd`    jobs, food, houses, cars, NPCs - edit numbers here
- `scripts/city_builder.gd` roads, buildings, shops (procedural)
- `scripts/world.gd`        world setup, day/night, GPS, NPC/traffic spawn
- `scripts/places_logic.gd` all shop / job / house / NPC menus
- `scripts/player.gd`, `car.gd`, `npc.gd`, `hud.gd`, `touch_controls.gd`

## Known limits of this first version
- Graphics are stylised low-poly, not photo-realistic.
- Traffic cars do not collide with you; NPCs walk set routes.
- Marriage and children are simple menu actions for now (no wedding scene or kids to control).
- No sound or music yet.
- Tested on Godot 4.3 on Linux with a software renderer; not yet tested on a physical
  Android device.
